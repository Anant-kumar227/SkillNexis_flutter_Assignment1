# Portfolio & Profile Flutter App

यह एक सुंदर और रिस्पॉन्सिव **Flutter Portfolio Application** है, जिसमें बॉटम नेविगेशन (Bottom Navigation Bar) का उपयोग करके एक व्यक्तिगत प्रोफ़ाइल, स्किल्स और इंट्रोडक्टरी स्क्रीन को प्रदर्शित किया गया है।

## ✨ फीचर्स (Features)

- **Bottom Navigation Bar:** तीन मुख्य स्क्रीन्स (`Hello Flutter`, `Info`, `Profile`) के बीच आसानी से स्विच करने के लिए।
- **Clean UI Layout:** शानदार और मॉडर्न कार्ड-बेस्ड डिज़ाइन और कस्टम विजेट्स।
- **Skills Showcase:** स्किल्स जैसे Flutter, Dart, HTML, CSS, JavaScript, और C++ को सुंदर चिप्स (Chips) के रूप में दर्शाया गया है।
- **Profile Summary:** कॉलेज, ब्रांच (B.Tech CSE), ईमेल और कांटेक्ट डिटेल्स के लिए एक व्यवस्थित लेआउट।

## 🛠️ उपयोग की गई तकनीकें (Tech Stack)

- **Framework:** Flutter
- **Language:** Dart
- **Design System:** Material Design

## 🚀 शुरुआत कैसे करें (Getting Started)

इस प्रोजेक्ट को अपने लोकल सिस्टम पर चलाने के लिए नीचे दिए गए स्टेप्स को फॉलो करें:

### 1. प्री-रिक्विजिट्स (Prerequisites)
सुनिश्चित करें कि आपके सिस्टम में Flutter SDK और गिट इंस्टॉल हो:
- [Flutter Installation Guide](https://flutter.dev)

### 2. क्लोन करें (Clone the Repository)
```bash
git clone https://github.com/Anant-kumar227/SkillNexis_flutter_Assignment1.git
cd SkillNexis_flutter_Assignment1
```

### 3. डिपेंडेंसी इंस्टॉल करें (Install Dependencies)
```bash
flutter pub get
```

### 4. ऐप रन करें (Run the Application)
```bash
flutter run
```
